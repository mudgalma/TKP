## Coding Guidelines

* Write clean, readable, maintainable, and production-quality code.
* Follow Python best practices (PEP 8) and use type hints where appropriate.
* Keep imports at the top of the file and remove unused imports.
* Write modular, reusable functions with a single responsibility.
* Use classes only when they improve code organization or encapsulate shared state; otherwise, prefer functions.
* Use meaningful variable, function, class, and file names.
* Avoid duplicated code; prefer simple, maintainable, and scalable solutions.
* Handle expected exceptions gracefully and avoid bare `except:` blocks.
* Add concise comments only when necessary; let the code be self-explanatory.
* Do not hardcode secrets, file paths, or configuration values.
* Before implementing, briefly explain the chosen approach and any important design decisions.
* Ensure the final code is well-structured, tested (pytest where applicable), and easy to understand.
